## Bitcoin Networks

### Mainnet

- Main network
- **Real Bitcoin** with monetary value
- Definitive and irreversible transactions

⚠️ **Use only with real bitcoins**

---

## Bitcoin Networks

### Testnet

- **Test bitcoins** with no value
- For testing and learning
- Faucets available to get test bitcoins

## Bitcoin Networks

### Signet

- **Test bitcoins** with no value
- More stable than testnet
- Ideal for workshops and training

## Connection Types

Sparrow can connect in several ways:

- **Private Bitcoin Core node**
- **Public Electrum server**
- **Private Electrum server**

---

## Bitcoin Core Node

- Your own Bitcoin node
- Maximum privacy
- Full control

---

## Electrum Servers

**Public Electrum server** :
- Connection to a third-party server
- Easier to configure

**Private Electrum server** :
- Your own Electrum server
- Good privacy/ease compromise

---

## Network Connection

### Clearnet

- Standard Internet connection
- Faster
- Less privacy

---

## Network Connection

### Tor

- The Onion Router
- Anonymous connection via the Tor network
- More privacy

## Create a New Wallet

- Menu → **New Wallet** → **Standard Wallet**
- Choose a name for your wallet
- Select the format: **Native SegWit (P2WPKH)**

---

## Native SegWit Format

- Modern and economical format
- Addresses starting with
  - `bc1...` (mainnet)
  - `tb1...` (testnet/signet)

---

## Generate Seed Phrase

The **seed phrase** is your backup key

- Usually **12 or 24 words**
- Randomly generated by Sparrow

⚠️ **CRITICAL** : Save immediately on paper

---

## Save the Seed

- **Write on paper** (never on computer/cloud)
- Verify that all words are correct
- Store in a safe and secret place
- Never share with anyone

⚠️ Loss of seed = **permanent loss of all bitcoins**

---

## Wallet Without Passphrase

- Standard wallet with seed only
- Easier to use
- If seed is compromised, funds are accessible

---

## Wallet With Passphrase

- Additional protection
- `seed + passphrase` = different wallet from `seed alone`
- Same seed can create multiple different wallets

---

## Passphrase Example

- Seed : `word1 word2 ... word12`
- Without passphrase → Wallet A
- With passphrase "MySecret123" → Wallet B

---

## Enable Passphrase

- In wallet settings
- Enable **Passphrase** option
- Enter your passphrase

**memorize or save separately**

⚠️ Loss of passphrase = **loss of funds in this wallet**

---

## Set a Password

The **wallet password** protects access to Sparrow

- Required each time you open the wallet
- Different from passphrase

⚠️ Does not protect if someone has your seed

---

## Best Practices

- Use a strong password
- Memorize it or store it in a secure password manager
- Do not confuse it with passphrase

---

## Account Concept

An **account** is a logical separation in your wallet

- Each account has its own addresses
- Useful for organizing your funds
- Example: "Savings" Account, "Expenses" Account

---

## Derivation Path

**Derivation Path**
- Mainnet
  - Account 0 : `m/84'/0'/0'`
  - Account 1 : `m/84'/0'/1'`

- Signet
  - Account 0 : `m/84'/1'/0'`
  - Account 1 : `m/84'/1'/1'`

---

## Sub-accounts

- Sub-accounts allow finer organization
- Each account can have multiple sub-accounts
- Useful for separating different uses

---

## Receiving Addresses

- Addresses to **receive** bitcoins
- Automatically generated by the wallet
- Each transaction should use a **new address**

---

## Change Addresses

- Addresses for **change** returned when sending
- Automatically generated by the wallet

If you send **0.1 BTC** but spend 1.0 BTC

**0.9 BTC** returns as "change"

---

## Change Address Example

- You have 1 BTC
- You send 0.3 BTC to someone
- Fees : 0.0001 BTC

**Change** : 0.6999 BTC returns to your change address

---

## View Accounts in Sparrow

  - receive
  - change

---

## Generate Receiving Address

- Select your wallet
- Go to the **Receive** tab
- Click on "Create new receiving address"
  
**A new address is generated**

---

## Display QR Code

- Display the **QR code** to facilitate sharing
- Copy the address to send it

---

## Pre-generated Addresses

- Sparrow can generate multiple addresses in advance
- Useful for receiving multiple payments
- Each address remains unique and valid

---

## Address Reuse

⚠️ Address Reuse **Avoid**

- Using the same address multiple times reduces privacy
- Allows linking your transactions together

Best practice **one address = one transaction**

---

## Receive - Demonstration

- Wallet → **Receive**
- Generate a new address
- Copy the address or display the QR code
- Use a Signet faucet to receive test bitcoins

---

## Verify Reception

- **Confirmations** : Number of blocks mined since your transaction
- More confirmations = more secure transaction
- Observe the transaction appear in the **Transactions** tab

---

## Number of Confirmations

- For small amounts : 1 confirmation often sufficient
- For large amounts : wait for 6 confirmations

---

## Why Move Between Accounts?

- Organize your funds
- Separate different uses
- Transfer to another account in the same wallet

---

## How to Move Between Accounts

- Open the **Send** tab
- In **Pay to**, enter a destination address
- Enter the amount to transfer
- Verify fees
- Create, sign and broadcast the transaction

**Note** : It's technically a normal transaction, but to your own wallet

---

## Transaction Creation

- Open the **Send** tab
- In **Pay to** :
  - Enter the recipient's Bitcoin address
  - Or scan a QR code
- Enter the **amount** to send
  - In BTC or sats
- Add a **label** to identify the transaction

---

### Fee Configuration

- **Fee slider** : Adjust transaction fees (sats/vB)
- Higher fees = faster confirmation
- Lower fees = slower confirmation
- Sparrow suggests appropriate fees

---

### Advanced Options

- **Replace-By-Fee (RBF)** : Allows increasing fees after sending
- **Coin selection** : Manually choose UTXOs to spend

---

### Verification Before Signing

- **Destination address** : Is it correct?
- **Amount** : Is it correct?
- **Fees** : Acceptable?

⚠️ **CRITICAL STEP** - Verify before signing

---

## Verification - Change Address

- **Change address** : Verify it belongs to you
  - Must be an address from your wallet

⚠️ If the change address is not yours, you lose these bitcoins

---

### Change Address Explanation

When sending, if you spend more than the amount to send

**Sending example**
- You have a UTXO of 1 BTC
- You send 0.3 BTC
- Fees : 0.0001 BTC

**Change** : 0.6999 BTC must return to your wallet

---

### Change Address Rule

The change address must **ALWAYS** be an address you control.

---

## Transaction Signing

- After verification, click **"Create Transaction"**
- Verify all details again
- Click **"Sign"**
- Enter your password if requested
- Transaction is signed with your private keys

---

### Transaction Broadcast

- After signing, click **"Broadcast Transaction"**
- Transaction is sent to the Bitcoin network
- Wait for confirmations
- Follow the transaction in the **Transactions** tab

---
