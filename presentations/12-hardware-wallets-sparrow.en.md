## What is a Hardware Wallet?

Maximum security for your private keys

- Offline key storage
- Protection against malware
- Visual transaction confirmation
- Multi-device support
- Guaranteed self-custody

---

## Supported Hardware Wallets

Compatible with Sparrow Wallet

- **Ledger**: Nano S, Nano S Plus, Nano X
- **Jade**: Blockstream Jade
- **SigSigner**: Open source solution
- **Trezor**: Model One, Model T
- And many more...
