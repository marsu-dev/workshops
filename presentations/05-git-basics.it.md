# Git Basics

non pianificato

Introduzione ai concetti di base di Git: creazione di repository, commit, branch e gestione delle versioni per i tuoi progetti.

---

## Obiettivi

- Comprendere i concetti fondamentali di Git
- Creare e gestire un repository
- Eseguire commit
- Lavorare con i branch
- Gestire le versioni dei tuoi progetti

---

## Cos'è Git?

Sistema di controllo versione distribuito

- Cronologia completa delle modifiche
- Collaborazione facilitata
- Gestione delle versioni
- Open source e gratuito
