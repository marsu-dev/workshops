# Installa Umbrel

non pianificato

UmbrelOS è un sistema operativo per server personali che consente di ospitare i propri servizi a casa: cloud, media, backup, domotica o nodo Bitcoin.

---

## Obiettivi

- Comprendere UmbrelOS
- Preparare l'hardware necessario
- Installare UmbrelOS
- Configurare i servizi di base
- Installare un nodo Bitcoin

---

## Cos'è UmbrelOS?

Sistema operativo per server personali

- Interfaccia web intuitiva
- Applicazioni preconfigurate
- Self-hosting
- Controllo dei tuoi dati
- Open source

---

## Hardware richiesto

Preparare il tuo server

- Raspberry Pi 4 o server x86
- Scheda SD o disco rigido
- Alimentazione adeguata
- Connessione di rete
- Considerazioni sullo storage

---

## Installazione

Configurare UmbrelOS

- Scaricare l'immagine
- Scrivere sul supporto di archiviazione
- Configurazione iniziale
- Accesso all'interfaccia web
- Configurazione di rete

---

## Servizi disponibili

Applicazioni Umbrel

- Cloud personale
- Server multimediale
- Backup
- Domotica
- Nodo Bitcoin

Installa e configura
