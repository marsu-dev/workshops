# Soroban Presentation

not planned

Soroban is a distributed directory server that allows storing and sharing information in a decentralized and anonymous manner.

It uses a peer-to-peer network with automatic synchronization between nodes.

Integration with Tor guarantees anonymity and censorship resistance.
