# Umbrel installieren

nicht geplant

UmbrelOS ist ein Betriebssystem für persönliche Server, das es ermöglicht, eigene Dienste zu Hause zu hosten: Cloud, Medien, Backups, Hausautomation oder Bitcoin-Knoten.

---

## Ziele

- UmbrelOS verstehen
- Die notwendige Hardware vorbereiten
- UmbrelOS installieren
- Grundlegende Dienste konfigurieren
- Einen Bitcoin-Knoten installieren

---

## Was ist UmbrelOS?

Betriebssystem für persönliche Server

- Intuitive Weboberfläche
- Vorkonfigurierte Anwendungen
- Self-Hosting
- Kontrolle über Ihre Daten
- Open Source

---

## Erforderliche Hardware

Ihren Server vorbereiten

- Raspberry Pi 4 oder x86-Server
- SD-Karte oder Festplatte
- Passendes Netzteil
- Netzwerkverbindung
- Speicherüberlegungen

---

## Installation

UmbrelOS einrichten

- Image herunterladen
- Auf Speichermedium flashen
- Erste Konfiguration
- Zugriff auf Weboberfläche
- Netzwerkkonfiguration
