## Objectifs

- Comprendre l'intégration hardware wallets avec Sparrow
- Configurer votre hardware wallet
- Utiliser Ledger, Jade, SigSigner, Trezor avec Sparrow
- Sécuriser vos transactions
- Gérer vos bitcoins de manière professionnelle

## Qu'est-ce qu'un Hardware Wallet ?

Sécurité maximale pour vos clés privées

- Stockage hors ligne des clés
- Protection contre les malwares
- Confirmation visuelle des transactions
- Support multi-devices
- Auto-custodie garantie

## Hardware Wallets supportés

Compatible avec Sparrow Wallet

- **Ledger** : Nano S, Nano S Plus, Nano X
- **Jade** : Blockstream Jade
- **SigSigner** : Solution open source
- **Trezor** : Model One, Model T
- Et bien d'autres...
