## Objetivos

- Comprender los conceptos fundamentales de Git

- Realizar commits
- Trabajar con ramas

---

## ¿Qué es Git?

Sistema de control de versiones distribuido

- Historial completo de modificaciones
- Colaboración facilitada
- Gestión de versiones
- Código abierto y gratuito
